# Миграции этапа 1

Миграция accounts 0004 исправлена в существующей цепочке до ввода системы в
эксплуатацию. На пустой PostgreSQL прежний вариант прекращал установку до
возможности запустить следующую исправляющую миграцию. Исправленный вариант
создаёт недостающие системные роли, сохраняет ID существующих ролей и привязки
пользователей, проверяет неизвестные и неоднозначные роли до изменения данных.
Повторный вызов безопасен. Уже применённая 0004 не запускается повторно.

Миграция 0006 возвращает Role под управление Django на уровне состояния
миграций без пересоздания таблицы. Таблица была создана исходной 0001;
исторические 0002–0005 сохраняют PostgreSQL-ограничения code NOT NULL/UNIQUE.

Рабочую БД нельзя заменять предоставленным SQL-дампом. Для существующей БД
сначала сравнивают фактические таблицы и django_migrations с release-версией,
делают резервную копию и проверяют восстановление на отдельном стенде.
Использование --fake/--fake-initial требует проверки соответствия схемы.
