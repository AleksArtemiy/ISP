# Приватные вложения

Единственный путь скачивания — `/prescriptions/files/<id>/download/`.
Доступ проверяется по учреждению предписания. MEDIA_ROOT не должен находиться
в публичном web root. Nginx/IIS не должны раздавать `/media/`: возвращать 404.
Это правило действует и на уже загруженные файлы. Имена путей в БД не меняются;
старые Windows-разделители поддерживаются. Символические ссылки наружу и
переходы `..` запрещены.

До записи проверяются число файлов (5), размер (10 МиБ каждый), расширение и
структура. Pillow декодирует JPEG/PNG, pypdf строго читает структуру PDF,
olefile читает контейнер и заголовки DOC/XLS, defusedxml и zipfile проверяют
OOXML DOCX/XLSX. Все библиотеки работают на Windows и Linux без libmagic DLL.
Зависимости закреплены в requirements.txt. Этот файл переведён из UTF-16 в
UTF-8 для переносимости инструментов сборки.

Зашифрованные документы, макросы, встроенные Office-объекты, внешние шаблоны
и активные PDF-действия отклоняются. Есть ограничения распакованного ZIP и
размеров изображений. Это проверка формата и известных активных конструкций,
а не утверждение об отсутствии любых вредоносных данных; перед production
проверяют необходимость антивирусного сканирования и его инфраструктуру.
Пользователь открывает документ в обновлённом локальном приложении.

Файлы возвращаются как attachment с application/octet-stream, nosniff и
private/no-store. Исходное имя не используется как путь. Файлы новых
неуспешных транзакций удаляются компенсирующим действием, ошибки очистки
логируются. Резервные копии БД и каталога файлов должны быть согласованы.

Ссылки на библиотеки: [Pillow](https://pillow.readthedocs.io/en/stable/reference/Image.html),
[pypdf](https://pypdf.readthedocs.io/en/stable/modules/PdfReader.html),
[olefile](https://olefile.readthedocs.io/en/stable/olefile.html).
